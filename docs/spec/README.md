# Comets — Web Application Specification

This specification describes the Comets application so it can be rebuilt from scratch as a **client-only web application** (HTML, CSS, vanilla JavaScript), hosted as static files on GitHub Pages. It is derived from the desktop application in this repository (`src/`, WinForms, .NET 8). The desktop app is the reference for behaviour, and the [test vectors](vectors/) are generated by running its source code.

The web app is a new product with the same capabilities. It is not a port of the desktop UI. Desktop windows, menus, dialogs and window management are replaced by what is natural on the web. Everything that computes, parses or writes data must match the desktop exactly, except for the deliberate decisions listed below.

## Conventions

- The key words **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT** and **MAY** are used as in RFC 2119.
- "Desktop" means the WinForms application in `src/` at the commit this spec was written against.
- Code references such as `EphemerisManager.CometXyz` name the desktop source a rule comes from. They are there for tracing only; the spec text is normative on its own.
- Angles are in **degrees** unless stated. Distances are in **AU**. Dates and times are **UTC** unless stated.
- `JD` is a Julian Day number. Desktop treats UTC as the dynamical time scale (there is no ΔT), and the web app MUST do the same.
- Number formats are given as .NET custom format strings (for example `0.000000`), because the desktop output is defined by them. [03-element-formats.md § Number formatting](03-element-formats.md#number-formatting) defines each one used, so that a JavaScript implementation can reproduce them exactly.

## Key decisions

These were agreed before the spec was written. Their consequences are spelled out in the linked documents.

1. **Web only.** The web app need not mirror desktop windows, menus or dialogs. It SHOULD feel like a natural web application ([01](01-product.md)).
2. **One canonical astronomy engine.** The desktop has two engines: the ephemeris engine, and a separate one inside the orbit viewer. The web app has one ([04](04-astronomy.md#decision-record-one-canonical-engine)):
   - comets and the Sun use the desktop ephemeris engine unchanged, so every ephemeris, graph, sort and filter value matches the desktop;
   - the orbit viewer draws comets with the same engine;
   - planets use Paul Schlyter's mean orbital elements, from the same family as the engine's Sun. They replace the orbit viewer's two-regime planet series.
3. **Client-only.** The app has no backend. It is static files on GitHub Pages, written in vanilla JS, HTML and CSS with no build step required ([01](01-product.md#platform-and-hosting)).
4. **Desktop-specific features are dropped**: proxy settings, per-program export folders, window position, always-on-top, child-window arrangement, the exit confirmation, BMP/GIF export, and keyboard navigation while the window is unfocused. The full list is in [01 § Dropped](01-product.md#dropped-desktop-features).
5. **All 21 element formats** are kept: 19 can be imported and exported, and 2 (Comet for Windows, NASA) are import-only, as on the desktop.
6. **Test vectors** come from the desktop sources, at a frozen clock of `2026-10-18 12:00:00 UTC` ([11](11-test-vectors.md)).
7. **Layered architecture.** A pure, DOM-free core; services behind small ports; a thin UI; the dependency rule enforced by lint and types ([12](12-architecture.md)).

Beyond these, the web app reproduces desktop behaviour, including its quirks. Fixing a quirk is a separate, explicit change. [10-quirks.md](10-quirks.md) lists the quirks so they can be decided one by one.

## Glossary

| Term | Meaning |
|---|---|
| Elements | The orbital elements of a comet: T, q, e, ω, Ω, i, plus magnitude parameters g and k |
| Designation | The comet identifier, e.g. `1P`, `C/2023 A3`, `73P-BT` (with fragment) |
| Full name (`full`) | Designation plus name as displayed, e.g. `C/2023 A3 (Tsuchinshan-ATLAS)`, `1P/Halley` |
| Database | All comets the user has imported (the *main collection*) |
| Selection | The database after the user's current filters and sort (the *user collection*); the default input of the ephemeris, graph, orbit viewer and element tools |
| MPC | IAU Minor Planet Center, the default source of elements (`Soft00Cmt.txt`) |
| Ephemeris | A table of computed positions of a comet over time |
| Tn | The perihelion date nearest to now (differs from T for periodic comets) |
